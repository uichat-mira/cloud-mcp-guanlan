# 观澜 Guanlan · Web 品牌物料

这套物料用于观澜 Web、Mira ID 应用展示、favicon、社交分享和产品文档。视觉核心不是“新闻眼睛”，而是 **地平线 / 远山 / 水面**：持续观察、保持距离、留下脉络。

## 标志

- assets/guanlan-mark.svg：主图形标志，优先使用。
- assets/guanlan-lockup-light.svg：浅色背景中英组合标。
- assets/guanlan-lockup-dark.svg：深色背景中英组合标。
- assets/guanlan-mark-16..1024.png：常用栅格尺寸。
- assets/guanlan-mark-256/512/1024.webp：WebP 应用图标。
- assets/favicon.ico：浏览器兼容 favicon。
- assets/guanlan-og-1200x630.png|webp|svg：社交分享卡。

## 字体

- 中文展示：Songti SC / STSong / Noto Serif CJK SC
- 英文展示：Iowan Old Style / Georgia
- UI 正文：Inter / PingFang SC / system-ui

## 用法

1. 图形标志可以独立作为 favicon、Mira ID 应用图标和插件图标。
2. 横版组合标用于官网、授权页、文档与应用列表；不要重新排字或拉伸图标。
3. 品牌图形不要叠加“眼睛、RSS、新闻纸”等第二套符号。
4. 浅色界面以 Cream / Ink 为主；深色界面以 Deep / Paper 为主，Dawn 只做点睛。
5. Tagline：**观世界 · 识时势**。这是品牌语，不代表观澜替 Agent 做价值判断。

运行时代码中的页面与 /brand 预览使用相同视觉语义；本目录是可交付的静态资产包。
